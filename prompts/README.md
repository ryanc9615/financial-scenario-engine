# Conversation prompts

Open **one new ChatGPT Project conversation per phase**. Use `phase_00.md` first; then follow numerical order through `phase_16.md`. The tutor protocol and engineering spec must remain available to the tutor. The same prompts are concatenated for uploading into ChatGPT Project references as `../docs/PHASE_PROMPTS.md`.

At the end of each phase, use `_end_phase_review.md`. If a chat is too long, use `_resume_phase.md` instead of beginning the following phase before completing the current one.

Do not mark a phase completed without observed tests and a verbal/practical understanding check.
